# Python Practice

## Overview

A structured learning repository focused on Python programming, automation scripting, API integration, software testing, and AI application development.

## Objectives

- Build strong Python programming fundamentals.
- Understand object-oriented programming.
- Develop practical problem-solving skills.
- Learn automation scripting and API integration.
- Explore AI and LLM application development.
- Follow professional coding and development standards.

## Technology Stack

- Python 3.14.10
- IntelliJ IDEA
- Virtual Environment (venv)
- pip
- Git and GitHub

## Coding Standards

- PEP 8 coding conventions.
- Meaningful variable and function names.
- Clean Code principles.
- Proper exception handling.
- Docstrings and type hints where appropriate.
- SOLID principles where applicable.

## Environment Setup

Create a virtual environment:

```powershell
py -3.14 -m venv .venv
```

Verify the Python interpreter:

```powershell
.\.venv\Scripts\python.exe --version
```

## Branching Strategy
